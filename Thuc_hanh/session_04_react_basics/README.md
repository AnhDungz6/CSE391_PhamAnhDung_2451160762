## 🎯 Learning Path

### Tuần 1: React Cơ Bản

1. Hiểu sự khác biệt giữa Vanilla JS vs React
2. Setup React project với Vite
3. Tạo component đầu tiên
4. Học JSX syntax

### Tuần 2: State & Props

1. Quản lý State với useState
2. Truyền Props giữa components
3. Event handling
4. List rendering

### Tuần 3: Mini Project

1. Xây dựng Category Filter
2. Xây dựng Contact Form

### Tuần 4: Portfolio Project

1. Xây dựng React Portfolio Website

## 🛠️ Requirements

- Node.js >= 14
- npm or yarn
- VS Code
- Basic JavaScript knowledge

## 📝 Cách Sử Dụng

1. **Đọc bài tập** trong thư mục `exercises/`
2. **Thực hành viết code** trong riêng folder
3. **So sánh với solution** trong thư mục `solutions/`
4. **Chạy project** từ thư mục `projects/`
